# 📱 PhonePe Transaction Insights

## 📌 Project Overview

This project analyzes PhonePe transaction, user, insurance, and geographical data using Python, SQL Server, and Streamlit.

The main objective is to identify transaction trends, user engagement, insurance performance, market expansion opportunities, and user growth patterns.

## 🎯 Project Objective

To analyze PhonePe data and generate meaningful business insights using SQL, Python, data visualization, and an interactive Streamlit dashboard.

## 🛠️ Technologies Used

- Python
- Pandas
- SQL Server
- PyODBC
- Matplotlib
- Seaborn
- Streamlit
- Jupyter Notebook
- Git & GitHub
